# Pull Request Template

Pull request from guest contributors are welcome! Whether you are adding content, fixing a padding issue, or correcting typos in the [Urtext](https://acim.iamalexbrady.com/acim/urtext/),
feel free to submit a pull request at our public repository hosted on [GitHub](https://github.com/iamalexbrady/iamalexbrady.github.io).

Please use the template provided below as the description of the pull request. Not all checkboxes are necessary, just check the ones you honestly did.

We currently do not have unit tests. Feel free to be the pull request that adds them.

---

## Description

Include the following:

* Link to [alex brady board](https://alexbrady.atlassian.net/jira/software/c/projects/ABB/boards/2) ticket (if applicable).
* Relevant motivation and context
* Summary of the changed files
* Any any changes required outside of this repository (e.g. 3rd party services)

## Type of change

- [ ] Bug fix (non-breaking change which fixes an issue)
- [ ] New feature (non-breaking change which adds functionality)
- [ ] Documentation update

## Checklist:

- [ ] My code follows the style guidelines of this project
- [ ] Code that may be difficult to understand has been commented
- [ ] I have made corresponding changes to the documentation
- [ ] My changes generate no new warnings
- [ ] I have visually inspected any new UI changes, and it's fine
